# Frontend prototype

This folder contains a static HTML/CSS/JS prototype matching the Figma layout (placeholders used).

- Open `index.html` or `signup.html` in a browser to preview.
- Replace files in `assets/` with actual exports from Figma when available.
- `css/style.css` contains the main styling. `js/app.js` has simple form handlers and placeholders to connect to your API.

To view locally, run a simple static server (recommended) from the project root:

```bash
npx serve frontend
```

Or open the files directly in the browser.
